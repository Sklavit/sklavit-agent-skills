# LinkedIn Technical Post & Medium Article Creator

Create high-quality technical content for engineers about emerging technologies, AI/ML, and software engineering best practices. This skill helps generate both LinkedIn posts and extended Medium articles.

## When to Use This Skill

Use this skill when the user wants to:
- Write a LinkedIn post about technical topics (AI, ML, software engineering)
- Create content for an engineering audience
- Extend a LinkedIn post into a comprehensive Medium article
- Get help structuring technical blog content
- Generate professional but engaging technical content

## Target Audience

- AI Engineers
- ML Engineers
- Software Engineers
- Technical professionals in emerging tech

## Content Approach

### Style Guidelines
- **Catchy but concentrated**: Hook readers fast, deliver value quickly
- **Professional**: Maintain credibility and technical accuracy
- **Personal when relevant**: "How I" over generic "How To"
- **Specific**: Use real examples, metrics, and outcomes
- **Balanced**: Acknowledge trade-offs and limitations

### Core Requirements
- **Main message**: Every post must have a clear takeaway
- **Argumentation**: Back claims with evidence, examples, or reasoning
- **Practical value**: Focus on insights engineers can use

## Creating LinkedIn Posts

### Step 1: Choose a Template

Read [references/linkedin_templates.md](references/linkedin_templates.md) (in this skill's directory).

Select from these templates based on content type:
1. **Problem-Solution-Insight**: Best for sharing technical lessons learned
2. **Technical Deep-Dive (Numbered List)**: Good for tips, principles, or frameworks
3. **Case Study / "How I"**: Ideal for personal experience and results
4. **Contrarian Opinion**: For challenging common beliefs
5. **Quick Technical Tip**: For concise, actionable advice

### Step 2: Craft the Content

Follow this structure:

1. **Hook (1-2 lines)**: Grab attention immediately
   - State a surprising result
   - Challenge a common belief
   - Ask a provocative question
   - Share a specific outcome

2. **Context (2-3 lines)**: Brief background on the problem/topic

3. **Main Content (3-5 points)**: Core insights, steps, or arguments
   - Use bullet points or short paragraphs
   - Be specific and concrete
   - Include metrics when possible

4. **Takeaway/Lesson**: What readers should remember

5. **Call to Action**: Thought-provoking question to spark discussion

6. **Hashtags**: 3-5 relevant tags (see templates for suggestions)

### LinkedIn Best Practices

- **Length**: 250-300 words optimal
- **Formatting**: Use line breaks between sections for scannability
- **Voice**: Professional but conversational; personal experience resonates
- **Code**: Brief snippets only (2-5 lines max)
- **Timing**: Tuesday-Thursday, 8-10am or 12-2pm are peak engagement times

## Creating Medium Articles

### Step 1: Understand the Scope

Read [references/medium_templates.md](references/medium_templates.md) (in this skill's directory).

Select from these templates based on content type:
1. **Technical Tutorial**: Step-by-step implementation guide
2. **Technical Deep Dive**: Comprehensive explanation of complex concepts
3. **Technical Opinion/Analysis**: Argumentative piece with evidence
4. **Technical Case Study**: Real-world engineering story with results

### Step 2: Structure the Article

All Medium articles should include:

1. **Title & Subtitle**: Clear, specific, keyword-rich
2. **Cover Image**: Required (suggest using Unsplash/Pexels)
3. **Introduction** (300-500 words):
   - Hook readers
   - State the problem
   - Promise value
   - Preview structure

4. **Body Sections** (1000-1800 words):
   - Use clear H2/H3 headers
   - Include code examples with extensive comments
   - Add diagrams, screenshots, or graphs
   - Show real metrics and outcomes
   - Provide context and reasoning

5. **Conclusion** (200-400 words):
   - Summarize key takeaways
   - Provide next steps
   - Link to resources

### Medium Best Practices

- **Length**: 1000-2500+ words (longer is fine for tutorials)
- **Depth**: Go deeper than LinkedIn; explain the "why" thoroughly
- **Code**: Full examples with line-by-line explanations
- **Visuals**: Architecture diagrams, before/after comparisons, metric graphs
- **Tone**: Professional but accessible; explain technical concepts clearly
- **SEO**: Use keywords in title, headers, and throughout content

## Extending LinkedIn Posts to Medium

When converting a LinkedIn post to a Medium article:

1. **Expand the hook** → Full introduction with context (300-500 words)
2. **Elaborate each point** → Dedicated sections (300-500 words each)
3. **Add technical depth** → Code examples, architecture diagrams
4. **Include implementation** → Step-by-step guide or detailed explanation
5. **Address edge cases** → Common problems, solutions, limitations
6. **Add supporting material** → Related concepts, alternatives, resources
7. **Provide industry context** → Why this matters, current landscape

**Example transformation:**

LinkedIn (280 words): "We cut latency from 2s to 80ms" with 4 bullet points

Medium (1800 words): Full article with:
- Background on system architecture
- Detailed problem diagnosis
- Investigation process
- Step-by-step solution with code
- Comprehensive metrics
- Lessons learned
- Resources and next steps

## Content Generation Workflow

### For LinkedIn Posts:

1. Identify the core message/insight
2. Choose appropriate template from references
3. Write a strong hook that captures attention
4. Structure content using template format
5. Ensure 250-300 word range
6. Add line breaks for scannability
7. Include thought-provoking question
8. Add 3-5 relevant hashtags

### For Medium Articles:

1. Determine article type (tutorial, deep-dive, opinion, case study)
2. Select corresponding template from references
3. Outline the structure with specific sections
4. Write introduction that hooks and promises value
5. Develop each section with:
   - Clear explanations
   - Code examples with comments
   - Relevant visuals
   - Real metrics/outcomes
6. Write conclusion with key takeaways
7. Add resources and further reading
8. Review against Medium checklist in references

## Tips for Engineering Audiences

### What Engineers Value:
- **Specificity**: Real numbers, concrete examples
- **Honesty**: Acknowledge what didn't work
- **Practicality**: Actionable insights they can use
- **Depth**: Technical details when relevant
- **Context**: Why decisions were made

### What to Avoid:
- Vague buzzwords without substance
- Generic advice without examples
- Overpromising without evidence
- Pure self-promotion
- Engagement bait ("Comment if you agree")
